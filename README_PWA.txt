COLA ELEITORAL 2026 — PWA

Como instalar no Android:
1. Publique esta pasta em um site com HTTPS (ex.: GitHub Pages, Netlify ou outro host HTTPS).
2. Abra o endereço no Chrome do Android.
3. Toque em “Instalar aplicativo” quando aparecer, ou no menu do Chrome escolha “Instalar app”/“Adicionar à tela inicial”.
4. Depois da primeira carga, a aplicação foi preparada para consultar os dados e fotos em cache offline.

IMPORTANTE: o PWA precisa ser servido por HTTPS para o service worker funcionar fora de localhost.
